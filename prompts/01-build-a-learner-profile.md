# Prompt 1 — Build a learner profile

Copy everything below the line. Answer the questions it asks you, in one go.

---

I'm designing a Project Based Learning project for one specific child, and I want
to start from who they are rather than from a topic. Help me build a learner
profile.

Ask me for anything missing from this list, all in one message — don't ask me one
question at a time:

- Grade and age
- Subjects this should cover
- Weeks available and hours per week
- Setting (homeschool / microschool / tutoring / other)
- Standards they need to hit, and which framework or state
- **Two or three specific interests** — things they actually do
- Observable strengths — things I've watched them do
- How they like to make things (build, write, draw, film, record, present,
  argue, work with data, teach, organise events)
- How they handle open choice: does it free them up or freeze them?
- How they feel about presenting to people
- Anything that makes learning harder: reading, getting started, organisation,
  finishing. "Nothing" is a fine answer.
- Whether they've done project work before
- Who can support them and how much
- What's around us a project could use — places, people, real problems
- Constraints: budget, transport, tech, fixed dates
- What I actually want out of this project — including the non-academic goal

**Please push back on me** if I give you:

- A vague interest like "reading", "sports", "animals", or "art". Ask for
  something specific — what you'd see them doing if you walked in unannounced.
- A trait instead of a behaviour for strengths — "smart", "creative", "hard
  worker". Ask what I've watched them do.

Then organise it back to me under these headings:

**Basics** · **What they need to learn** · **Who they are** · **How they work** ·
**What helps them learn** · **The situation** · **What I want**

Plus three short prose sections in my own words:

- **What lights them up** — including the *shape* of the interest, not just the
  topic. Someone who loves animals because they like caring for things needs a
  different project from someone who loves animals because they like classifying.
- **What gets hard** — and specifically: what do they do when they don't know
  what to do?
- **What we've already tried** — what worked, what didn't, and why I think so

Two rules:

- Describe difficulties **functionally**, never with a diagnosis or a test score.
  "Loses the thread on multi-step directions", not a label.
- **Do not generate standards codes.** If I don't know mine, write the standard
  as plain text and mark the code "TBD" so I can look it up. A plausible-looking
  fake code is worse than none.

Don't suggest a project yet. Just the profile.
