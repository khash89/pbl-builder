# Prompt 4 — Map the four phases

Paste your profile and confirmed foundations, then this.

---

The foundations are settled. Now map the project across four phases.

**Launch** → **Build Knowledge** → **Develop & Critique** → **Present**

All four, even though my project is short.

## First, the entry event

Something my learner **sees, does, or goes to** — not an explanation of the
project. Design it so they naturally ask the questions I want answered.

Then list the questions you'd expect them to raise, and check those against my
standards. If a standard has no question pointing at it, the entry event is
aimed wrong — fix the event, don't add a lecture.

## Then, milestones for each phase

For each milestone:

- What gets accomplished
- **At least one question written as my learner's question**, not my objective
- What actually happens — lessons, research, visits, building, practice
- What exists at the end

## These must all be true, and tell me where each one is

- [ ] **At least one critique cycle before the Present phase**, with revision
      scheduled as its own separate session afterwards
- [ ] **At least two reflection points, in two different phases** — on how the
      work is going, not just on what they learned
- [ ] **Formative assessment in both middle phases** — and for each one, what
      I'd actually *do* if it showed a problem
- [ ] Content is not front-loaded. Instruction arrives when a question demands it.

## Because there's no class, also tell me

- **Who gives the critique.** Name the kind of person — a sibling, a
  grandparent, a co-op, an expert, or me deliberately in a critic's role. If I
  don't decide this in advance it won't happen.
- **What happens when my learner gets stuck** — the steps, in order, before it's
  a crisis. "Help them" is not a protocol.
- **Where the slack is**, and what I should cut first if we run behind. Tell me
  what I should *never* cut.
- **Where you think this will stall**, and why.
