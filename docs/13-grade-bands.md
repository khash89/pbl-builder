# Grade Bands

The eight design elements don't change. How you run them does.

---

## Pre-K – Grade 2

**All eight elements are achievable.** Early-childhood PBL is real PBL, just shorter and more concrete.

| | |
|---|---|
| **Length** | 1–3 weeks. Beyond that the arc stops being holdable. |
| **Sessions** | 20–30 minutes of project work. Two short blocks beats one long one. |
| **Launch** | Spread across several days, with read-alouds between to let questions accumulate. |
| **Need-to-knows** | Whole-conversation, over days. Pictures. Three prompts: what I wonder about / what I think is true / how I could find out. |
| **Product** | Physical, drawn, or spoken. Picture book, model, or a tour they give. |
| **Audience** | Beyond the household still counts — grandparents, neighbours, a younger class, the library staff. |
| **Success skill** | **One dimension of one skill.** Not one skill — one row. |
| **Rubric** | Two or three criteria, with pictures, reviewed one at a time out loud. |
| **Reflection** | Verbal, with drawing. Two prompts maximum. |
| **Critique** | "One thing I liked, one thing I wondered." Heavily modelled first. |
| **Roles** | Even a five-year-old can be the project manager if it has a picture on it. |

**What surprises people:** they can handle a genuinely open driving question. What they can't handle is holding it in mind for six weeks. Shorten the project, not the question.

**Whole-class or whole-family products** work well alongside individual ones at this age.

## Grades 3–5

The sweet spot for a first project — enough independence to do real work, not yet self-conscious about presenting.

| | |
|---|---|
| **Length** | 3–5 weeks. |
| **Sessions** | 45–60 minutes. |
| **Need-to-knows** | Can generate independently, but need help getting past surface questions. Model one good one. |
| **Reading** | The real constraint. Tier the sources; let them choose the entry point. |
| **Product** | Wide range available. Choice boards work well. |
| **Success skill** | One skill, one or two dimensions. They can self-assess with guidance. |
| **Critique** | Praise-Question-Suggestion with sentence starters. Gallery walk works. |
| **Choice** | Three or four options across content and product. |
| **Experts** | Can prepare and ask their own questions with support. Video calls work well. |

**The main risk** is a project that's really a research report with a craft component. Push on the driving question: is there a decision or a design in it, or just a topic?

## Grades 6–8

Capable of substantially more than they're usually given, and self-consciousness arrives.

| | |
|---|---|
| **Length** | 4–6 weeks. |
| **Sessions** | 60–90 minutes. |
| **Driving question** | They can write it themselves from the need-to-know list. Worth the extra day. |
| **Product** | Policy proposals, podcasts, campaigns, real events. |
| **Audience** | Genuinely public — a council, a board, a community group. |
| **Success skill** | Full rubrics. Independent self-assessment. |
| **Critique** | Tuning protocol. They can facilitate it. |
| **Choice** | High, including audience and product. |
| **Experts** | Can arrange the contact themselves, which is worth having them do. |

**Watch for:** the audience becoming terrifying somewhere around here. Don't respond by shrinking it — build the ramp. This is the age where dropping the public product does the most long-term damage, because the retreat gets internalised.

**Also watch for:** cynicism about invented stakes. A middle-schooler can smell a fake problem immediately and will disengage without telling you. If the impact is honestly nothing, say so and lean on the authentic *process* instead.

---

## Grades 9–12

Can do professional-grade work, and often do when the audience is real.

| | |
|---|---|
| **Length** | 6–10 weeks. |
| **Driving question** | Theirs. Genuinely contested, with no answer you already hold. |
| **Product** | Business plans, policy proposals to real bodies, original data collection, published work. |
| **Audience** | Actual stakeholders with actual decisions to make. |
| **Success skill** | Full rubrics, self-directed, with written justification. |
| **Critique** | Charrette, tuning protocol, plus outside expert critique. |
| **Choice** | Set the constraint, not the option. Then get out of the way. |
| **Data** | Can design and run their own survey or measurement programme. Big unlock. |

**The best products at this level involve original data** the learner collected. It's the thing that most reliably moves the work from "well-researched" to "nobody else knew this."

**Watch for:** over-scoping. A sixteen-year-old will propose a project that would take a team six months. Constrain the scope, not the ambition.

**And the paradox:** the more capable the learner, the more tempting it is to skip the critique cycle because the first draft is already decent. Decent isn't the target.

## Adjusting for PBL experience, not just age

Age is one axis; experience is the other, and it's often more predictive.

A twelve-year-old on their first project needs more structure than the same learner on their fourth — and more than a nine-year-old who has done three. The profile's `pbl_experience` field exists for this.

| Experience | Adjust |
|---|---|
| `none` | Narrower choice menu. More scaffolds. Shorter project. You run more of the routines. Expect the first project to be the hardest for both of you. |
| `some` | Widen the choices. Hand over the calendar and the project wall. They can run one routine themselves. |
| `experienced` | They can write the driving question, pick the product, arrange the expert, and run their own critique. Your job shrinks to the parts that need an adult. |

**The first project is the expensive one.** It teaches the routines as well as the content, which is why it takes longer and feels less efficient. That cost isn't repeated.

---

## What never changes

Regardless of age:

- All four phases of the [Project Path](05-project-path.md)
- A critique cycle **before** the presentation, with revision time after it
- A real audience beyond the household
- Reflection during the work, not only at the end
- **One** success skill
- Every scaffold has a fade plan
